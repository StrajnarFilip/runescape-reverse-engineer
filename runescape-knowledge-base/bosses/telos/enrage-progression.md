# Enrage progression toward 4000%

Start with a reproducible 0% clear. Record which visible cues led to each action, how much food and prayer each phase used, and where the character lost targeting. Add difficulty after the current route survives a missed input and a delayed transition.

| Enrage | Guide reference | Validation to add |
| --- | --- | --- |
| 50% | Virus in phases 2 and 3 | Identify the debuff and verify the cleanse in each beam. |
| 100% | Phase 5 begins | Verify arena entry, beam selection, golem handling and the bomb recovery route. |
| 150% and 250% | Telos can break stuns and binds. The cooldown and phase-5 immunity change. | Measure from observed Freedom and stun outcomes. Published cooldowns disagree. |
| 500% | P4 font HP cost reaches its cap | Record each payment and remaining HP under golem pressure. |
| 1000% | Rock hazards and changes to stun recovery and the P5 bomb | Verify rock cues and exits. Rehearse font-based interception. |
| 4000% | Maximum enrage | Verify a full run at the selected enrage before recording a clear. |
