Goal
----

Handle what each phase demands beyond attacking and praying: where to stand,
when to move, and what to target.

* Phase 1: tendrils, melee distance, green beam.
* Phase 2: black beam, Onslaught, virus.
* Phase 3: red beam, golems and the meter.
* Phase 4: the three fonts, golems, target switches.
* Phase 5: golems, beam choice, rocks, the final bomb.

Offline implementation (2026-11-13)
-----------------------------------

The user explicitly requested offline implementation before P4/A2 calibration.
There is one phase module plus shared geometry and MechanicsEngine. Default
phase rules are unvalidated guide leads and cannot authorize any movement.
Calibrated rules require an exact client SHA-256 and enrage band; they do not
transfer across builds or enrage. No current real strategy is enabled.

Movement requires a fresh same-session calibrated arena anchor, observed
orientation/bounds, relative safe tiles, known player tile and complete
validated hazard data. Unknown hazard types/states or missing geometry block
the engine. No absolute instanced-arena coordinates are embedded. Candidate
tiles exclude observed danger and require a positive fresh A2 path verdict;
entering a beam is distinct from moving out of a dangerous area. Target and
font/cleanse interactions require known entity/options and an A2 verdict.
Unmapped NPC HP cannot establish a living target.

can_send rechecks the same current response. note_sent waits for a newer native
position/target or explicit hazard resolution. Selecting an object does not
prove a font was charged or a virus cleansed. Unknown/partial omission does
not acknowledge an interaction. Timeouts and changed sessions latch faults.

Sixteen tests pass, including synthetic sequences for all five phase handlers,
relative-anchor rotation, build/enrage scope, missing A2, stale/unknown data,
font/target validation and postconditions. The legacy capture has a golden
no-movement log because it lacks P4/A2 data. All 10 CTest suites pass in the
Windows x64 Release build (94 Python tests). These tests are not recorded P4
hazard validation; that acceptance requirement remains outstanding.
