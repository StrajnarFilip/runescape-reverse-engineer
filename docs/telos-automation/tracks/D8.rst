Goal
----

The process that runs everything and can stop everything: the entry point, the
run modes, the kill switch, the watchdogs and the per-kill report.

Read first
----------

* S0a contracts and ``replay.py``.
* ``python/rs3_reader/native.py`` (``Reader``, event cursors, loss counters).
* ``docs/prayer-flick.rst`` on scene epochs and event-queue gaps.
* ``python/rs3_reader/jsonl_stream.py``.

Owns
----

* ``python/rs3_reader/bot/supervisor.py``
* ``python/rs3_reader/bot/__main__.py``
* ``tests/python/test_bot_supervisor.py``

Depends on
----------

S0a. Loads whichever producers exist; a missing producer is simply absent.

Delivers
--------

* ``python -m rs3_reader.bot --mode shadow|assist|full`` with a per-producer
  enable list. Shadow mode uses the recording fake actuator.
* A global kill-switch hotkey that stops input and releases every held key.
* Watchdogs that stop input on: stale snapshot, event-queue loss, scene-epoch
  or process change, lost window focus, planner FAULT, an unknown Telos
  sequence, or an unconfirmed intent past its timeout.
* A JSON Lines session log and a compact per-kill report.
* Kill-count and wall-time caps.

Done when
---------

Tests trip every watchdog with synthetic input and confirm input stops and keys
are released each time, and shadow mode runs against a replayed capture.

Needs the user
--------------

The preferred kill-switch key.

Offline implementation (2026-11-13)
-----------------------------------

The user deferred live input and track L. The CLI recognizes shadow/assist/full,
but assist/full stop before acquisition with an explicit L-authorization error.
Shadow owns only a RecordingActuator, optionally shared with D6, and never
selects a hardware backend. Missing producer modules are listed as absent;
errors inside available modules are not hidden. Producer output is bounded.

``python -m rs3_reader.bot --mode shadow --capture capture.jsonl --enable ...``
runs without importing native input. ``--pid`` explicitly selects a read-only
NativeTelemetry observer. It registers a configurable Windows global stop key
(default Ctrl+Alt+Pause), uses foreground checks and releases resources on exit.
No global hotkey or live reader was opened during this implementation.

Watchdogs cover stale/unavailable frames, unknown/lost native queues, changed
process/scene/build, clock/sample regression, injected focus loss, component
faults, unknown Telos events and arbiter confirmation timeout. Stops latch and
close the arbiter/device plus closeable producers. Shadow replay does not
pretend to know OS focus; an injected focus checker is tested independently.

Wall-time and verified-kill caps are separate from game ticks. A kill/death
requires a fresh explicit validated encounter_result envelope; NPC HP zero,
despawn or raw stage alone does not establish a result. JSON Lines contain
per-frame proposals, a compact session report and verified per-kill summaries.
Normal caps do not count as watchdog failures. No game success is inferred
from a recording-fake acceptance.

Seventeen D8 tests trip the watchdogs, verify fake held-key release, exercise
caps/results and run shadow CLI/replay without native imports. The real legacy
capture has a golden no-input log and correctly trips on missing queue data.
The Windows x64 Release build and all 10 CTest suites pass (95 Python tests).
Delayed replay ages nested result envelopes too; an old result does not
become fresh simply because a newer frame is being evaluated.
