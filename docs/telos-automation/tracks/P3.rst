P3 - Player effects
===================

:Status: waiting for live session
:Wave: 1
:Branch: ``telos/P3``
:Kind: C (native DLL)

Shared rules and procedure: ``../README.rst``.

Goal
----

Read the local player's buffs and debuffs with identity, stacks and expiry.
Required set: Berserk, Bloodlust, overload, adrenaline renewal, anima virus,
stun and bind, Resonance, Anticipation, Freedom, Devotion, Barricade,
Immortality and Disruption Shield. Stretch goal: the special stored in an
Essence of Finality amulet.

Read first
----------

* ``docs/telos-melee-research.rst``, sections "Prayer and defensive decisions"
  and "Essence of Finality identity and special attacks".
* ``docs/inventory-and-abilities.rst`` (how VarClient timers are read; Bone
  Shield tier from VARP 11212).
* ``src/variables.c``, ``src/abilities.c``.

Owns
----

* ``src/effects.c``, ``src/effects.h``, ``include/rs3/effects.h``
* ``tests/native/test_effects.c``
* ``docs/validation/effects-validation.json``
* Own registration lines in the shared wiring files.

Depends on
----------

S0a for the field names.

Delivers
--------

``WorldState.player.effects[]``: effect identity, stacks, remaining time and a
validity reason. An effect that was not observed is unknown, not absent, unless
the whole effect list was read completely.

Done when
---------

Each required effect is validated live or reported as unmapped, fixture tests
pass, and the report lists the source variable or structure of every effect.

Needs the user
--------------

The 2026-11-11 session labelled Anticipation, Freedom, Resonance and overload.
See ``docs/validation/effects-validation.json``. The overload expiry countdown is available; the three defensive sources were
labelled but their durations remain unvalidated. Presence, stacks and early
cancellation remain unknown.

Next controlled checks (only when recording is confirmed active):

* Repeat Anticipation and Freedom separately, reporting each displayed duration.
* Cast Resonance, then consume it with one ordinary incoming hit before expiry.
* Trigger Berserk, Bloodlust, adrenaline renewal, Devotion, Barricade and
  Immortality individually when available; label casts and expiry/consumption.
* Cast Disruption Shield, then take one hit; label shield consumption.
* During a manual Telos attempt label a stun, bind and anima virus.

Do not infer a buff from an ability's cooldown. No automated input is enabled.

Requests
--------

Integration: register the effect header/storage in ``src/context.h`` along with
own shared wiring. This is the same minimal private-snapshot registration pattern
used by P1/P2; no existing public struct was extended. No other track files changed.

A complete native buff-list decoder and EoF stored-special identity are still
unmapped. Downstream decision tracks must require effect flags and must not use
a positive end timer as proof that a defensive is active.
