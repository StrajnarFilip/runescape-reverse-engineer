Fixture tests cover appearance, disappearance and scene changes.

Implementation and evidence
---------------------------

* ``rs3/hazards.h`` documents the additive copy-out ABI: info 80 bytes, entry
  88 bytes, explicit validity/reasons, bounded capacity and dropped counts.
* C builds candidates from committed NPC identities and P1 poses, after the
  parent frame's final context check. It issues no additional remote reads and
  caches nothing across frames. Process/scene/sample mismatches invalidate tiles.
* Eight ID/name pairs were observed in the original-profile P2 capture. Matching
  names or IDs alone remain unknown candidates. Font/golem kind and variant
  identify the actor; mechanics validation, areas, roles and timers remain unknown.
* ``WorldState.hazards`` receives partial candidate records through the existing
  telemetry adapter. Coverage is never complete, including a zero-entry result.
* Full checks: 12 CTest targets passed, including 78 Python tests and ten native
  hazard test cases. ``docs/validation/hazards-validation.json`` records limits.
